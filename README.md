# Week 1 Assessment – Git, Terminal and Notebook

## Project Overview
This project analyzes employee data using Python, Pandas, Jupyter Notebook, Git and GitHub.

## Folder Structure
- `data/` – Employee CSV dataset
- `notebooks/` – Jupyter Notebook analysis
- `reports/` – Backup CSV files
- `src/` – Exported Python script

## Setup Instructions
1. Install Python 3.10 or above.
2. Install required packages:
   `pip install pandas notebook nbconvert`
3. Open the project folder.
4. Run the Jupyter Notebook:
   `jupyter notebook`

## Analysis Findings
1. Total employees: 10.
2. Chennai employees: 5.
3. Average employee salary: 38200.
4. Employee data contains four departments.
5. Salary average was measured using `%timeit`.

## Tools Used
Python, Pandas, Jupyter Notebook, Git and GitHub.
